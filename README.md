## Projects

### [BIM Clash Portal](https://github.com/ask-io/clash-portal) &nbsp;[![](https://img.shields.io/github/v/release/ask-io/clash-portal?style=flat-square&color=00D4FF&label=version)](https://github.com/ask-io/clash-portal/releases)

An automated engineering coordination tool that parses BIM clash detection matrices into filtered, color-coded, multi-sheet priority reports.

- **Core impact:** replaced a hardcoded 71×71 matrix boundary with a dynamic edge-detection scan, so it now handles spreadsheets of arbitrary size.
- **Error handling:** async fetch/parser pipeline routes backend validation exceptions straight to custom UI status elements instead of failing silently.
- **Stack:** FastAPI, openpyxl (data-only formula evaluation), vanilla JavaScript, HTML/CSS.

### [BunkSafe](https://github.com/ask-io/BunkSafe)

A college attendance management app. It calculates safety margins for skipping or attending classes to hit a target attendance percentage.

**Evolution**
- Started as a native Android app in Kotlin (`com.abhijit.bunksafe`), using dynamic color parameters to flag safe vs. critical attendance states.
- Rebuilt as a cross-platform PWA for wider device support and simpler deployment.
- Frontend: HTML5, Tailwind CSS, JavaScript. Persistence: browser LocalStorage.

**Features**
- Calculates the exact number of classes you can safely skip or must attend to stay above your target attendance percentage.
- Swipeable, card-based views for tracking each subject's percentage individually.
- Onboarding flow for entering course schedule, subjects, and target thresholds.
- Color-coded status at a glance: green for safe zones, red/orange for critical attendance levels.
